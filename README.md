# ShopsBuilder Community Feedback

Welcome! 👋 This is the public place to share ideas, report bugs and show what you've built with **ShopsBuilder**.

👉 **[Open Discussions](https://github.com/orgs/ShopsBuilder/discussions)**

| | Category | Use it for |
|---|---|---|
| 💡 | **[Ideas](https://github.com/orgs/ShopsBuilder/discussions/categories/ideas)** | Feature requests and improvements |
| 🐞 | **[Bug Reports](https://github.com/orgs/ShopsBuilder/discussions/categories/bug-reports)** | Something not working as expected |
| 🙌 | **[Show and tell](https://github.com/orgs/ShopsBuilder/discussions/categories/show-and-tell)** | Stores, themes and workflows you've built |

## How it works

1. **Search first** — your idea or bug may already be there.
2. **Upvote with 👍** instead of posting a duplicate. We use votes to prioritise.
3. **Use the form** — each category has a short template so we get the details we need.
4. **Follow along** — we'll reply in the thread and update it as things move.

## Please keep in mind

- This space is **public**. Never post passwords, API keys, payment details or customer personal data.
- For **security vulnerabilities** or account-specific issues, contact us privately via in-app support.
- Be kind and constructive. ❤️
